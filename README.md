# <img width="32" height="32" alt="tablet-analyzer-logo" src="https://github.com/user-attachments/assets/d25c84da-def9-4efa-b31f-bd502a4420de" /> Tablet Analyzer
a tool for analyzing tablet report rate and consistency with statistics and visualizations. made mainly to test experimental, high report-rate tablet firmware.

## Functions
- accurate polling statistics!
  - view the average report rate, 1% report rate lows, and 0.1% lows across a rolling time window
  - track the standard deviation (spread) of report rate and interval jitter
  - benchmark with a multi-factor consistency score
- graphs/visualizations: line graphs and histograms, split view and full screen views
- connects directly to the tablet with WebHID for accurate stats that bypass browser throttling
- cursor trail using coalesced pointer events

## Requirements
only works with a Chromium-based browser for now (like Google Chrome and Edge). i might add support for other browsers later.

# <img width="32" height="32" alt="tablet-analyzer-logo" src="https://github.com/user-attachments/assets/d25c84da-def9-4efa-b31f-bd502a4420de" /> Tablet Analyzer
A tool for analyzing tablet report rate and consistency with statistics and visualizations. Made mainly to test experimental tablet firmware.
## Functions
- polling statistics:
  - view average report rate, 1% report rate lows, and 0.1% lows across a rolling window
  - standard deviation (spread) of report rate and interval
  - consistency score combining multiple factors
- graphs:
  - report interval graphs (line graph and histogram)
  - pressure graph for supported tablets
  - display options for each graph type
- connects directly to tablet for accurate stats
